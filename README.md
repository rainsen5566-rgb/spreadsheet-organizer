# 試算表整理小工具

提供試算表轉檔、Excel 多工作表合併與 PDF 匯出、依欄位分類拆檔。

## 下載與使用

請到本儲存庫的 [Releases](https://github.com/rainsen5566-rgb/spreadsheet-organizer/releases) 頁面下載已正式發布的使用者套件。

下載最新版的 `SpreadsheetOrganizer_v版本號.zip`，解壓後開啟 `試算表整理小工具.exe`。移轉到另一台 Windows 電腦時，只需複製這個執行檔。

- 上方拖入檔案後立即處理。
- 下方可一次加入多檔或分次追加，按「轉檔」後開始。
- Excel 匯出 PDF 與自動調整欄列需要桌面版 Microsoft Excel。

## 程式內更新

從 v1.8 起支援檢查更新。程式啟動時在背景檢查，也可點選「檢查更新」。有新版時顯示更新內容，使用者同意後才下載及安裝。

更新會核對 GitHub Release 提供的 SHA-256，將上一版備份存到 Windows 使用者的本機更新資料夾，並在新版啟動失敗時恢復原版。程式資料夾需可寫入，網路無法連線時仍可使用原有功能。啟動檢查每台電腦最多每六小時一次，手動檢查不受這個間隔限制。

更新僅取得版本資訊及下載程式，不會上傳匯入檔案或工作資料。

## 維護者發布方式

每次發布使用遞增的正式版本標籤，例如 `v1.8`、`v1.9`、`v2.0`。附上供既有更新器下載的 `SpreadsheetOrganizer.exe` 和對應的單檔使用者 ZIP，再發布為正式最新版。程式依標籤版號判斷更新。

使用者 ZIP 內只有 `試算表整理小工具.exe`。維護用原始碼留在本機。
